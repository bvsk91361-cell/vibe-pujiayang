# 本地运行与演示

当前预览：http://localhost:3004/ 。分支：feat/glass-review-workspace。

```powershell
cd "E:\桌面\vibecode\vibe-pujiayang-git"
node scripts/seed-product.js
$env:PORT="3004"
node server.js
```

需要 Node.js 22.14 或更新的兼容版本；本机内置 SQLite 仍会输出 experimental 提示，不影响已完成的本地验证。已有实例运行时不重复启动同端口。

后端启动时从被忽略的 `.env` 读取 YOSHUB_API_KEY、YOSHUB_BASE_URL、YOSHUB_MODEL。默认地址 https://api.yoshub.com/v1，模型 deepseek-v4-flash。不要把密钥填入浏览器、聊天、前端代码或Git。服务绑定127.0.0.1。

```powershell
npm test
```

自动测试使用 mock，不消耗模型余额。真实模型验收通过本机智能推荐/空闲查询/周报入口手动进行。请求有超时与输出预算；周报最多两次，查询与推荐单次。进程内设调用上限，重启计数清零，不代表平台账户的总用量。

建议演示路径：发现 → 五种场景轮播 → 设备中心 → 详情 → 场景创作方案 → 添加/移出/替换 → 检查时间 → 单件预约 → 我的预约；另一条路径：兴趣选择 → 智能推荐带入问题 → 生成装备组合 → 加入方案。

数据位于 data/borrow-lab.sqlite，备份时优先使用 SQLite 一致性备份，勿在运行中仅复制主文件而遗漏WAL。种子脚本不覆盖现有预约和用户偏好。本轮保留了用户操作数据，浏览器方案加件验收使用未保存草稿，未增加用户预约。

当前需要 Node 后端和 SQLite 才能完整运行。旧 build:pages 的静态预览不等同于本轮完整产品；未部署、未做真实登录、未做离线预约。manifest只是应用外观入口，不能据此宣称PWA离线能力或已满足应用商店上架要求。
