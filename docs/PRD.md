# 借一下：实验室设备预约（题库第5项）

作者：蒲嘉洋；讨论组：第 10 组。补做日期：2026-10-07。

## 用户与问题
课程拍摄、访谈和小组汇报需要借用器材。同一器材被两个人约到同一时段会影响安排。原型用于演示预约规则与验证流程，不接入学校现有借用系统。

## 三个核心功能
1. 浏览三件器材：数码相机、便携投影仪、录音笔。
2. 创建预约：填写姓名、日期与时段；拒绝同器材、同日期、同时段的重复请求。
3. 管理预约：按填写姓名筛选“我的预约”、查看到期状态并取消；本地保存到 JSON 文件，刷新或重启保留，取消后释放时段。线上静态演示保存当前浏览器。

## 可执行验收
- [x] 三张器材卡片渲染；实际选投影仪后表单同步变化。
- [x] 有效预约成功后在列表回显。
- [x] 重复预约显示明确提示，接口返回 409，记录仍只有一条。
- [x] 空姓名、过去日期、不存在的日期、未知器材、非法时段均被拒绝。
- [x] 浏览器刷新后记录仍在；重建存储读取由测试验证；取消后可预约原时段。
- [x] 自动化测试覆盖以上业务规则及并发重复请求。
- [x] 姓名筛选精确匹配；切换全部视图能看到他人记录。姓名筛选不等于登录鉴权。
- [x] 过去日期和时段结束时显示已到期；使用中和未来状态由边界测试验证。

上述勾选为 Codex 实际运行的验收，不代替蒲嘉洋本人独立操作与讲解。三张卡片均点击、服务完整重启等额外手工检查仍可继续补充。

## 本版范围
使用本机共享记录；没有账号登录与借还审批。取消功能仅适合课程演示，所有访问者都可操作。不把本版直接用作真实学校借用系统。
