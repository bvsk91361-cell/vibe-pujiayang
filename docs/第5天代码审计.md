## 必须修：真实发现并已修复

1. **中文跨 HTTP 数据块乱码**：server.js 的 `body += chunk` 单独解码每段字节。用实际分块请求复现 `'���嘉洋' !== '蒲嘉洋'`。改成按字节计数、Buffer 拼合后一次解码；对应回归用例通过。提交 `0cdf868`，修复前后日志入库。
2. **Windows 静态预览模块不执行**：Python 服务把 JS 返回为 text/plain，页面只剩布局。改用 `scripts/preview-pages.js` 明确 MIME；页面卡片、表单、持久化实际恢复。公网资源还改成相对路径，避免项目子目录错位。

上述两项必须修已关闭；这是本次实际发现项的结论，不声称不存在其他缺陷。

## 其他风险及处置

| 风险 | 处置 |
|---|---|
| 幻觉 API、依赖漂移 | Node 官方内置模块；Papa Parse 固定5.5.3，实际调用 unparse/parse 验证 |
| 并发重复写入 | Node 写操作串行，真实两个请求只允许一个写入；浏览器跨标签页不具备服务器事务保证 |
| 姓名脚本注入 | 页面用 textContent 生成文本；没有用姓名拼 innerHTML |
| CSV 公式注入 | escapeFormulae=true；测试 =1+1 导出后为带前导单引号的文本 |
| 密钥/数据进入 Git | 私钥在本机 .ssh；data、.env 忽略；没有将预约数据或凭据发布到 Pages |
| 外部许可证 | Papa Parse MIT 文本随固定版本入库；未替本项目擅自声明统一许可证 |
| 本地版缺少用户鉴权 | 只监听127.0.0.1；不把它作为学校真实共享服务。公网版仅为每浏览器演示 |
| 静态存储失败、数据丢失 | 写入失败明确报错；清理网站数据会删除本机演示记录，下一版再设计共享后台 |
