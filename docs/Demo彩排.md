## 备用分支
| 故障 | 操作 | 必须说明 |
|---|---|---|
| AI/额度/超时失败 | 返回方案，轻量Vlog规则组合→空闲→预约 | 这是规则推荐，不冒充实时AI |
| 断网 | 本机Node/SQLite走设备→方案→预约；展示已有AI证据 | 无离线AI/离线PWA |
| 公网打不开 | 使用localhost:3004 | 新后端未部署；旧静态站不代表新产品 |
| 数据异常/日期过期 | 独立演示账号、新日期，先查台账 | 不清空用户库/覆盖SQLite及WAL |
| 浏览器缓存 | 强制刷新；再重开页面核对账号 | 不盲清localStorage草稿 |
| 端口占用 | 核对已有项目进程直接使用 | 不强杀其他服务 |
| 视频不可播放 | 走本地路线与截图/日志 | 未制作视频前不声称备份完成 |
