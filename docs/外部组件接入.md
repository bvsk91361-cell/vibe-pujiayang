# 第 4 天：外部组件接入与存量代码阅读

实际补做：2026-10-07；执行者：Codex，蒲嘉洋委托。新增预约 CSV 导出，不增加 npm 安装步骤。

## 结构地图与接入点

`public/index.html` 加载 Papa Parse → `public/app.js` 点击导出 → `public/export-csv.js` 将预约对象转成四列表格 → `Papa.unparse` 处理引号、逗号和换行 → Blob 下载。预约规则仍只有 `src/booking.js` 一份，静态构建复制该模块，Node 测试通过转出口引用同一文件。

采用 Papa Parse 5.5.3，来源为官方仓库的固定版本：

- https://github.com/mholt/PapaParse/tree/5.5.3
- 文档：https://www.papaparse.com/docs
- 保存为 `public/vendor/papaparse.min.js`，MIT 许可证一并保存为 `PAPAPARSE-LICENSE`。
- SHA256：`3553fb8bdf5b8004ce5531e6827e81c8b34e7b3992677967754544064e97b016`。

先用 `Papa.unparse` 官方格式的 fields/data 例子编写可执行测试，再接入按钮。测试包含中文、逗号、双引号、换行，解析后逐字段比较；姓名以 `=` 开头时使用 `escapeFormulae: true` 加前导单引号，防止表格软件当作公式。组件缺失时显示错误，不假装导出成功。

## 遇到的适配问题

原页面资源使用 `/app.js`，项目站点部署在 `/vibe-pujiayang/` 下会请求错误根路径。改成 `./app.js`、`./style.css`；后端 API 路径仍只用于 Node 本地版。线上版明确使用浏览器本地存储，没有跨设备共享或后端部署的声称。
