# 借一下：校园器材预约电梯稿

蒲嘉洋个人补做，2026-10-07。文稿由 Codex 根据当前项目整理，未声称经过组内互讲或教师审题。

## 给谁解决什么问题

给需要拍摄、访谈和小组汇报的同学提供一个器材预约原型。把器材、日期和时段放在同一条记录里，拒绝重复占用。课堂用它演示需求、验证和 Git 交付流程；尚未接入学校真实借用系统。

## 核心功能恰好三个

1. 浏览：选择相机、投影仪或录音笔。
2. 预约：填写姓名、日期和时段，拒绝重复请求。
3. 管理：查看与取消记录，释放原时段。

## 为什么做得完

采用 JavaScript、Node.js HTTP 和文件读写，原生 HTML/CSS 表单；对应程序设计、Web 基础和文件存储知识。本版不引入登录、审批、支付或跨校区库存。JSON 持久化与浏览器演示分开说明，三条核心功能都有自动化验证。

## 最大风险与对策

同一时段被重复预约：后端将写操作串行执行，并用并发测试验证两个重复请求只有一个成功。线上静态版仅保存当前浏览器数据，不能作为真实多人库存系统。

## 审题三问的个人自审

- 用户真实存在吗：校园拍摄与汇报会用器材；需求尚未访谈确认，不冒充用户调研。
- 能砍掉一个功能吗：CSV 导出属于附加功能，可砍；三条核心功能组成最小闭环。
- 第一眼演示什么：选录音笔、提交预约，再提交相同时段，看重复拒绝。

教师审题与本人独立讲解仍需实际发生；本文件提供可审查的个人稿。
