`test/reservation-view.test.js:10:1`
测试名：“到期页面标记：过去日期、时段结束边界、使用中与未来日期”。
原始错误：
```text
Expected values to be strictly equal:
'已到期' !== '待使用'
code: ERR_ASSERTION
expected: '待使用'
actual: '已到期'
TestContext.<anonymous>
test/reservation-view.test.js:12:10
```

根因：`new Date(2026,9,7,8,59)`按运行器本地时区解释。UTC下是北京时间16:59，09:00–11:00已经到期；测试却按北京时间08:59期望“待使用”。应把夹具写成`new Date('2026-10-07T08:59:00+08:00')`，不放宽到期断言。
