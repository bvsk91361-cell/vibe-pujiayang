# 正式选题：5. 实验室设备预约系统

蒲嘉洋个人项目，2026-10-07明确对应题库第5项。此前实现是手册第1天器材预约热身；在本人提供八个选题并询问对应关系后，将既有代码延续为这个正式题目。没有声称已实现其他七个题目或已经接入大模型。

一句话：把实验室设备的预约时段排明白，避免冲突，让个人能查看、取消并识别到期预约。

## 当前最小闭环

| 题库要求 | 当前实现和证据 |
|---|---|
| 设备台账 | 三条只读样例设备：相机、投影仪、录音笔；含标识、名称和用途。不是学校真实资产库，未提供台账CRUD |
| 时段预约、冲突检测 | 器材+日期+时段唯一，Node写操作串行；规则与真实HTTP/并发测试 |
| 我的预约/取消 | 按表单填写姓名筛选“我的预约”，姓名变化立即更新；取消后释放时段。姓名筛选不是身份认证 |
| 到期提醒 | 过去日期/今日已结束时段显示“已到期”，开始至结束之间“使用时段中”，未来“待使用”；页面每分钟更新，不发邮件 |

本地 Node 版用 JSON 文件；公开静态版用每浏览器存储，均复用唯一规则模块。新增筛选与到期边界两组测试后总计13组全通过，提交 `912e270`；云端运行 https://github.com/bvsk91361-cell/vibe-pujiayang/actions/runs/37565757651 实际成功。

## 电梯稿仍保持三个核心功能

1. 浏览设备台账。
2. 创建预约并拒绝冲突。
3. 管理我的预约、取消与到期页面标记。

CSV导出为附加能力，不占核心功能名额。语音、邮件、支付、真实多设备共享库存不在第6天范围。
