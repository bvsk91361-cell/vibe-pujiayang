## 最大卡点、原始报错与真实修复

第一次 HTTPS 推送返回 `403 Access denied`。在 PowerShell 运行推送脚本时，出现：

```text
error: failed to execute prompt script (exit code 1)
fatal: could not read Password for 'https://pujiayang-vibe@gitee.com': No such file or directory
```

清除外部密码提示设置后，仍报相同错误；当时浏览器已登录，但 Git 推送仍需独立认证。最终改用 Windows OpenSSH：我在 Gitee 网页添加公钥，Codex 明确指定本机密钥，收到 `successfully authenticated`，随后推送成功。这是本次真实急救案例，不是编造的应用崩溃。它涉及 `推送到Gitee.ps1`（仓库外的本机辅助脚本）与仓库本地 SSH 配置；修复没有把密码、私钥或令牌写入仓库。
