# Borrow Lab界面候选版与验收

2026-10-07；分支feat/glass-review-workspace；本轮待蒲嘉洋本人检查，不更新公开部署。

## 参考与原创边界

- Apple HIG Materials：https://developer.apple.com/design/human-interface-guidelines/materials 。参考玻璃导航与内容分层、克制透明效果；网页实现为CSS近似，不是苹果原生Liquid Glass API。
- Apple HIG Motion：https://developer.apple.com/design/human-interface-guidelines/motion 。交互反馈简短，提供prefers-reduced-motion停用；高对比与减透明样式有降级。
- shadcn/ui：https://github.com/shadcn-ui/ui 。参考清晰的组件职责、表单和确认对话框组织；MIT开源，本轮没有复制其React实现或增加依赖。
- DayFlow：https://github.com/dayflow-js/calendar 。参考日期/时间信息组织；本轮七日选择器为原生JS实现，没有复制源码或采用它的框架依赖。

没有宣称这些项目是未经证实的“世界百强UI”。当前CSS相机和SVG设备均为本项目原创代码绘制；既有Papa Parse依旧保留其MIT许可。

## 本轮实际改变

搜索及分类、日期/时段联动、根据台账计算空闲、当前姓名的待使用数量、未来七天计划占比、可退出的取消确认弹窗、普通预约与AI独立的失败状态。
所有用户/模型文本使用textContent；只有固定的原创SVG通过innerHTML渲染。统计为真实记录计算，不使用虚构预约数、利用率或用户评价。

## 已运行的验证

- 本地20组自动化测试全通过，包含5条业务规则、真实HTTP与并发、UTF-8、CSV、静态存储、筛选、时间边界及AI模拟异常。
- 1440×1000桌面和390×844手机检查未出现横向溢出；浏览器记录分别为scrollWidth1425≤1440、375≤390。
- 点击投影仪→表单设备同步→14:00时段预约→概览1条/空闲减少→重复请求被拒绝。
- 取消弹窗先“保留预约”，记录保留；再确认取消，记录清空/时段释放。
- 搜索“投影”仅显示投影仪。
- 未配置AI时显示503兜底，普通预约可继续。
- 截图在验收证据/界面候选版。本轮模拟AI测试不是国内模型实际调用证明。
